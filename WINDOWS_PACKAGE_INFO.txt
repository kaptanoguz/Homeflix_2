🚀 WINDOWS'TA YAPILACAKLAR:

1. ZIP dosyasını çıkarın
   → windows_build_package/ klasörü oluşacak

2. Python 3.8+ yükleyin (yoksa)
   → https://www.python.org/downloads/
   → Kurulum sırasında "Add Python to PATH" seçmeyi unutmayın!

3. windows_build_package klasörüne girin

4. build_windows.bat'ı çift tıklayın
   VEYA cmd'de: python build_windows.py

5. Bekleyin... (10-15 dakika)

6. BITTI! ✅
   dist/Homeflix/Homeflix.exe

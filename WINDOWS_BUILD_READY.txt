WINDOWS'TA KURULUM:
════════════════════════════════════════════════════════════

1. Python yükleyin: https://www.python.org/downloads/
   (Python 3.8 veya daha yeni)

2. Proje dosyalarını kopyalayın (tüm klasör)

3. Komut satırında çalıştırın:
   
   build_windows.bat
   
   VEYA
   
   python build_windows.py

4. Bekleyin (10-15 dakika)

5. Hazır! ✅
   📍 dist/Homeflix/Homeflix.exe
   📍 dist/HomeflixInstaller.exe (NSIS kuruluysa)
